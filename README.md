# LifeQuest English

**Skills first, money later.**

Game nhập vai giúp người lớn mất gốc học tiếng Anh bằng cách sống một đời người: đào đồ, bán hàng, chạy bàn, giao hàng, lên cấp, chọn môn phái, nâng cấp phòng trọ. Mỗi món đồ, mỗi tình huống là một từ hoặc mẫu câu tiếng Anh thật.

## Chơi thử
Mở file `index.html` bằng trình duyệt (Chrome trên điện thoại hoặc máy tính).

## Đưa lên mạng (Cloudflare Pages hoặc Netlify)
Kết nối kho GitHub này, **không cần lệnh build**, thư mục xuất bản là thư mục gốc (`/`).

## Thêm từ vựng
```
node tools/validate-words.js data/words/*.json   # kiểm tra
node tools/build-data.js                          # gộp dữ liệu vào game
```
Chi tiết cho AI làm tiếp: xem `CLAUDE.md` (Claude) hoặc `GEMINI.md` (Gemini).
